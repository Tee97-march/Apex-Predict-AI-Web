🔄 How To Run APEX Predict AI
Follow this production sequence each day after preparing the day's football fixtures.
1
📥 Import Fixtures
Run the fixture importer in Google Apps Script. This places the day's football fixtures into the APEX Match Database.
FIRST
2
🧠 Run Data Pipeline
Enrich the imported fixtures with the available football data and prepare the records for AI calculation.
RUN
3
🎯 Run APEX Smart Gate
Smart Gate evaluates the qualified records and prepares the final selection pool, with a maximum of 30 matches.
MAX 30
4
🤖 Run APEX AI Engine
The AI Engine calculates the prediction, final confidence, risk level and recommended market.
RUN
5
🌐 Open APEX Web App
Refresh the web app. Dashboard, Predictions, Analysis, Statistics, Live Scores, Leagues and Head To Head read the current backend results.
ONLINE
